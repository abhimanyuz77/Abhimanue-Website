# From Zero to Hired — Digital Fulfilment via Signed URLs (learn.abhimanue.in Django Backend)

This document specifies how to deliver the book files (**PDF + EPUB** and the five
toolkit resources) after a successful ₹99 Razorpay payment, using **time-limited
signed download URLs generated by the `learn.abhimanue.in` academy Django backend**.

It is written so it can be handed directly to the Django developer (or AI agent)
working on the learn.abhimanue.in codebase. The payment side is already built and
deployed — this document covers the remaining fulfilment work.

## Architecture

```
abhimanue.in                        hexagonknow.com                        learn.abhimanue.in (Django)
────────────                        ────────────────                        ─────────────────────────
from-zero-to-hired.html
  │ "Get Your Copy – ₹99"
  ▼
abhimanue-book-payment.html
  │ 1. create-order (₹99 fixed server-side)
  │ 2. Razorpay Checkout
  │ 3. verify-payment (HMAC + capture)
  │
  │ After verified payment, redirect buyer to the LMS claim endpoint:
  └───────────────────────────────────────────►  GET /books/from-zero-to-hired/claim/
                                                     ?order_id=order_xxx
                                                     &payment_id=pay_xxx
                                                     &name=...&email=...&phone=...
                                                  4. Django verifies the payment
                                                     server-to-server via hexagonknow.com
                                                     check-payment (already deployed):
                                                     /api/abhimanue-book-payment
                                                       ?action=check-payment&payment_id=...
                                                  5. Validates: paid + amount 9900 paise
                                                     + product_id 'from-zero-to-hired'
                                                  6. Creates BookPurchase (idempotent by
                                                     payment_id)
                                                  7. Generates time-limited signed URLs
                                                     for PDF + EPUB + toolkit
                                                  8. Renders download page + emails the
                                                     links to the buyer
```

**Key principle:** the LMS never trusts the redirect parameters. The only
authoritative proof of payment is the server-to-server `check-payment` call to
hexagonknow.com, which reads the payment directly from Razorpay.

from django.db import models


class BookPurchase(models.Model):
    PRODUCT_ID = "from-zero-to-hired"

    payment_id = models.CharField(max_length=64, unique=True, db_index=True)
    order_id = models.CharField(max_length=64, db_index=True)
    name = models.CharField(max_length=200, blank=True)
    email = models.EmailField(db_index=True)
    phone = models.CharField(max_length=20, blank=True)
    amount = models.PositiveIntegerField(default=9900)   # paise
    currency = models.CharField(max_length=8, default="INR")
    download_count = models.PositiveIntegerField(default=0)
    emailed_at = models.DateTimeField(null=True, blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    def __str__(self):
        return f"{self.email} — {self.payment_id}"

## A3. Views

```python
# books/views.py
import requests
from django.conf import settings
from django.core import signing
from django.core.mail import send_mail
from django.http import FileResponse, Http404
from django.shortcuts import render
from django.utils import timezone
from django.views.decorators.http import require_GET

from .models import BookPurchase

CHECK_PAYMENT_URL = (
    "https://hexagonknow.com/api/abhimanue-book-payment"
    "?action=check-payment&payment_id="
)
EXPECTED_AMOUNT = 9900        # paise — ₹99 (server-side truth, never trust the client)
EXPECTED_PRODUCT = "from-zero-to-hired"
SIGNING_SALT = "book-download"
LINK_MAX_AGE = 72 * 3600      # signed download links live 72 hours
MAX_DOWNLOADS = 10            # safety cap per purchase


def _signed_link(request, purchase_id, file_key):
    token = signing.dumps(
        {"pid": purchase_id, "file": file_key},
        salt=SIGNING_SALT,
    )
    return request.build_absolute_uri(f"/books/download/{token}/")


@require_GET
def claim(request):
    """Buyer lands here after verified payment on hexagonknow.com.

    Query params (sent by the payment page redirect):
      order_id, payment_id, name, email, phone, signature, product, payment_status
    None of these are trusted for payment proof — we re-verify server-to-server.
    """
    payment_id = (request.GET.get("payment_id") or "").strip()
    order_id = (request.GET.get("order_id") or "").strip()
    if not payment_id or not order_id:
        return render(request, "books/claim_error.html", status=400)

    # 1) Server-to-server verification against hexagonknow.com / Razorpay
    try:
        check = requests.get(
            CHECK_PAYMENT_URL + payment_id, timeout=15
        ).json()
    except requests.RequestException:
        check = None

    verified = bool(
        check
        and check.get("success")
        and check.get("paid")
        and check.get("order_id") == order_id
        and check.get("amount") == EXPECTED_AMOUNT
        and check.get("product_id") == EXPECTED_PRODUCT
    )
    if not verified:
        return render(request, "books/claim_error.html", status=402)

    # 2) Idempotent purchase record (keyed by Razorpay payment_id)
    email = check.get("student_email") or (request.GET.get("email") or "").strip()
    purchase, created = BookPurchase.objects.get_or_create(
        payment_id=payment_id,
        defaults={
            "order_id": order_id,
            "name": check.get("student_name", ""),
            "email": email,
            "phone": check.get("student_phone", ""),
            "amount": check.get("amount", EXPECTED_AMOUNT),
        },
    )

    # 3) Fresh signed links (regenerated on every claim — safe to revisit)
    links = {
        "pdf": _signed_link(request, purchase.id, "pdf"),
        "epub": _signed_link(request, purchase.id, "epub"),
        "toolkit": _signed_link(request, purchase.id, "toolkit"),
    }

    # 4) Email the links (first successful claim only)
    if created or purchase.emailed_at is None:
        _send_download_email(request, purchase, links)

    return render(
        request,
        "books/downloads.html",
        {
            "purchase": purchase,
            "links": links,
            "link_hours": LINK_MAX_AGE // 3600,
            "claim_url": request.build_absolute_uri(),
        },
    )


@require_GET
def download(request, token):
    """Serves a file only if the signed token is valid and not expired."""
    try:
        data = signing.loads(
            token, salt=SIGNING_SALT, max_age=LINK_MAX_AGE
        )
    except (signing.BadSignature, signing.SignatureExpired):
        return render(request, "books/link_expired.html", status=403)

    try:
        purchase = BookPurchase.objects.get(id=data["pid"])
    except BookPurchase.DoesNotExist:
        raise Http404

    if purchase.download_count >= MAX_DOWNLOADS:
        return render(request, "books/link_expired.html", status=403)

    files = getattr(settings, "BOOK_FILES", {})
    key = data["file"]
    if key not in files:
        raise Http404

    purchase.download_count += 1
    purchase.save(update_fields=["download_count"])

    return FileResponse(
        open(files[key], "rb"),
        as_attachment=True,
        filename=files[key].name,
    )


def _send_download_email(request, purchase, links):
    claim_url = request.build_absolute_uri(
        f"/books/from-zero-to-hired/claim/"
        f"?order_id={purchase.order_id}&payment_id={purchase.payment_id}"
    )
    subject = "Your copy of From Zero to Hired (PDF + EPUB)"
    body = (
        f"Hi {purchase.name or 'there'},\n\n"
        "Thank you for purchasing From Zero to Hired — Digital Edition.\n\n"
        "Your secure download links (valid for 72 hours):\n"
        f"  PDF:   {links['pdf']}\n"
        f"  EPUB:  {links['epub']}\n"
        f"  Toolkit (5 resources): {links['toolkit']}\n\n"
        "If a link expires, reopen your download page anytime:\n"
        f"  {claim_url}\n\n"
        "Start building the career you want, one action at a time.\n\n"
        "— Abhimanue Udayan / Hexagon Know\n"
    )
    try:
        send_mail(
            subject,
            body,
            settings.DEFAULT_FROM_EMAIL,
            [purchase.email],
            fail_silently=True,
        )
        purchase.emailed_at = timezone.now()
        purchase.save(update_fields=["emailed_at"])
    except Exception:
        pass  # download page still works — log for follow-up
```

Notes on the code above:

- Import `from django.utils import timezone` for `emailed_at`.
- `files[key].name` assumes `pathlib.Path`; adjust to `os.path.basename` if using strings.

## A5. Settings — private file storage

**The book files must live outside any public static/media directory.** Keep them
in a directory served only through the signed `download` view:

```python
# settings.py
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent

# Private storage — NOT under /static/ or /media/
BOOK_FILES = {
    "pdf": BASE_DIR / "private_files" / "books" / "From-Zero-To-Hired.pdf",
    "epub": BASE_DIR / "private_files" / "books" / "From-Zero-To-Hired.epub",
    "toolkit": BASE_DIR / "private_files" / "books" / "From-Zero-To-Hired-Toolkit.zip",
}

# Signed URLs use SECRET_KEY by default. Use a dedicated salt (done above) so
# book tokens can't be confused with other signed values in the project.
```

Django's `signing.dumps(..., salt=...)` with `SECRET_KEY` is sufficient — the
tokens cannot be forged or read by the buyer, and `max_age` enforces expiry.

### Option B — cloud presigned URLs (S3 / Cloudflare R2)

If the LMS already stores private files in S3 or R2, `download` can redirect to a
short-lived presigned URL instead of streaming the file:

```python
import boto3  # works for both S3 and R2 (S3-compatible endpoint)

def _presigned(file_key, expires=900):
    s3 = boto3.client("s3", endpoint_url=settings.R2_ENDPOINT_URL)
    return s3.generate_presigned_url(
        "get_object",
        Params={"Bucket": settings.R2_BUCKET, "Key": f"books/{file_key}"},
        ExpiresIn=expires,
    )
```

Then in `download`, after token validation:
`return redirect(_presigned(data["file"]))`. Keep the Django-signed token in front
(15-minute presigned expiry is fine because the buyer can always regenerate from
the claim page).

# PART C — Optional: Razorpay webhook for reliability

The redirect can be lost if the buyer closes the tab mid-payment. For full
reliability, add a `payment.captured` webhook in the Razorpay dashboard pointing
at the LMS as well:

```
https://learn.abhimanue.in/books/webhook/razorpay/
```

The webhook handler must:

1. Verify the `X-Razorpay-Signature` HMAC-SHA256 of the raw body with the
   **webhook secret** from the Razorpay dashboard (Dashboard → Settings →
   Webhooks). Use a *webhook* secret, not the key secret.
2. Read `event = payload["payload"]["payment"]["entity"]`.
3. If `entity.notes.product == "from-zero-to-hired"` and
   `entity.status == "captured"` → `get_or_create` a `BookPurchase` from the
   entity fields (`id`, `order_id`, `email`, `contact`, `notes`) and send the
   download email (reuse `_send_download_email`, generating links server-side
   with an absolute base URL, e.g. `https://learn.abhimanue.in`).

The webhook and the claim endpoint converge on the same idempotent purchase
record, so ordering does not matter.
